## Concept & Objectives

Create a centralized platform that connects risk reduction efforts across departments, providing automated threat monitoring and response capabilities. Enable rapid deployment with no-code configuration and seamless data integration to reduce resource requirements while supporting compliance with global third-party risk regulations.

## Outcomes

- Expanded the design system and component library using Storybook, creating a reusable package across applications with Yarn Workspaces and an internal package library.
- Built a custom authentication experience using AWS Cognito from scratch with React and TypeScript in collaboration with our backend team, integrating MFA capabilities to help customers fulfill compliance requirements.
- Migrated the frontend to use Vite, aiming to reduce build times by ~70% compared to our previous build tool, Webpack.
- Modernized the codebase using Tailwind CSS, aiming to ease maintenance pain points of legacy CSS and targeting a ~40% reduction in development time day-to-day.
